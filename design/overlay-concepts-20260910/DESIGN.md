# 랜디픽 화면 방향 비교 — 구현 전 시안

## 범위
기존 WPF 앱을 수정하지 않는 로컬 HTML 비교 보드. 세 안은 동일한 가상 플레이
상태(40라, 13스토리 완료, 불릿 재료 2/3)를 표현한다. 실제 분석 결과나 현재 추천이 아니다.
게임 배경은 사용자가 제공한 화면이며 외부에 전송하지 않는다.

## 조사와 판단
- Blitz TFT 공식 구성 화면: 아이콘으로 완성 구성을 먼저 보여주고 상세는 탭으로 분리.
  https://blitz.gg/overlays/tft
- Hearthstone Deck Tracker 공식 저장소의 overlay/app 이미지: 게임 가장자리의 잔여 수량과
  별도 관리 창 분리. 저장소의 구형 예시이므로 현재 외형이 아닌 공간 배치 원칙만 참고.
  https://github.com/HearthSim/Hearthstone-Deck-Tracker
- Outplayed 공식 도움말의 가로 dashboard: 기록/서비스 상태를 주 게임 화면과 분리.
  https://support.overwolf.com/en/support/solutions/articles/9000208995-how-to-use-outplayed
- StyleGallery supporting-pane: 핵심 작업과 보조 정보를 분리, 좁으면 세로 재배치.
  https://raw.githubusercontent.com/changeroa/StyleGallery/main/patterns/split-sidebar/supporting-pane.md
- 실제 이미지 4장을 내려받아 직접 확인했다. Mobalytics는 접근 차단, MetaTFT는
  정적 응답에 화면이 없어 검증된 시각 근거에 포함하지 않는다.
- 브라우저 내장 WebView는 eval worker에서 지원되지 않아 별도 Bun 프로세스로 검수한다.
- 서브에이전트 모델 사용량 제한으로 병렬 시각 검수는 실행할 수 없다. 직접 검수한다.

## 시안
A 집중형: 320px 안팎의 작은 행동 카드. 재료 3전설 상태는 항상 보임.
B 경로형: 420px 안팎의 세로 조합 보드. 진행할 목표와 남은 조합 수량을 위계화.
C 분리형(추천): 작은 인게임 카드와 별도 복기/계획 창. 긴 설명과 기록은 게임 밖.

## 토큰과 구성
배경 #090c11, 표면 #111720/#18212b, 테두리 #2c3744, 글자 #f4f6f8,
보조 #adb9c7, 강조 #efc666, 완료 #72dfb0, 경고 #ffaf80.
안별 강조: A 금색, B 청록 #80d8cf, C 담청 #a5baff.
본문 Malgun Gothic/system-ui 14px, 설명 13px, 카드 제목 20px, 보드 제목 48px.
간격 4/8/12/16/24/32/48, 반경 8/12/16px. 큰 숫자 tabular-nums.
패널은 불투명에 가까운 어두운 배경; 과도한 금색 테두리, 긴 보유 목록은 제외.

## 공통 원칙과 프리미티브
- 현재 행동 카드: 아이콘/짧은 명령/추가 총수량/완료/남음/단축키.
- 세 전설 체크 행: 검은수염, 시키, 스모커를 소유 여부와 이름으로 구분.
- 상태 줄: 라운드와 스토리, 정상/인식 대기/완료를 문자로 표현. 깜빡임 없음.
- 선택위습: 사용 추천과 실제 사용을 구분, 보관량 강조.
- 타임라인: 실제 이벤트인 듯 꾸미지 않고 모든 예시를 시안 데이터로 명시.
- 비교 보드만 문서 전체 스크롤. 인게임 패널에 이중 스크롤 없음.
- 900px 아래 시안 세로 배치, 600px 아래 화면 축소 아닌 유동 폭.
- 탭 버튼으로 가상 상태 전환. 게임 입력이나 동의·전송 기능 없음.
- reduced-motion, 키보드 포커스, 색상 외 라벨, 링크 출처 제공.

## 수용 한계
실제 게임 조작, 반투명 WPF 성능, 물리 DPI는 이 HTML 시안으로 검증하지 않는다.
참고 이미지의 로고/화풍을 제품 브랜드로 복제하지 않는다. 선택 후 별도 구현한다.

## 메인 창 확장 — 사용자 선택 B
오버레이는 B 경로형으로 방향 선택됨. 메인 창은 별도 `main-window.html`에서
세 구성을 비교한다: 1 계획 중심(추천), 2 단계별 보드, 3 패·기록 중심.
B의 청록 진행 강조와 같은 유닛/상태 토큰을 사용한다. 브랜드 표식만 금색.
왼쪽 탐색, 가운데 전체 계획, 오른쪽 지금 행동을 구분하며 1100px 아래는
보조 영역을 아래로 배치한다. 760px 아래 탐색은 가로 목록으로 전환한다.
메인 창 시안 높이는 고정하지 않고 문서가 스크롤한다. 예시 데이터는 실제
추천이 아니며 상태 전환·시안 전환만 작동한다. 게임 조작 버튼은 만들지 않는다.
