# 랜디픽 프론트엔드 조사 및 시안

`index.html`을 열면 참고 화면과 A/B/C 시안을 비교할 수 있습니다.
상단의 **조합 안내 / 결과 확인 중 / 게임 시작 전** 버튼으로 세 안을 동시에 바꿉니다.
이 파일은 로컬 시안이며 게임 입력, 서버 전송, 실제 동의 처리 기능은 없습니다.

## 판단

추천은 **C 분리형**입니다. 게임 위에는 행동·수량·재료 3전설 상태를 남기고,
전체 계획과 기록은 별도 창에서 봅니다. 단일 모니터에서 창 전환이 싫다면 B가
대안입니다. A는 가장 단순하지만 전체 목표 확인에는 불리합니다.

공통 개선:
1. 금색 테두리와 긴 안내를 반복하기보다 현재 행동만 강조합니다.
2. “이미 만들었는데 또 만들어야 하나?”를 총수량/완료/남음으로 해소합니다.
3. 검은수염·시키·스모커의 소유 여부를 상시 표시합니다.
4. 정상 인식, 결과 확인 중, 연결 대기를 별도 상태로 표현하고 깜빡이지 않습니다.
5. 퀸 전환, 항로 진단, 통계 설명은 기본 조작 화면에서 제거합니다.

## 실제 확인한 참고 화면

| 참고 | 확인한 것 | 랜디픽 적용 판단 |
|---|---|---|
| Blitz 공식 TFT overlay | 구성 아이콘, 구성 탭, 게임 배경과 구분된 표면 | 목표 3전설 체크 행, 접히는 계획 |
| Hearthstone Deck Tracker 공식 README | 가장자리 카드 수량, 별도 덱 관리 창 | 고정 수량 열, 오버레이/관리 창 분리 |
| Outplayed 공식 도움말 | 별도 게임 dashboard, 상태 구획, 이벤트 북마크 설명 | 기록을 별도 창에서 검토 |
| StyleGallery supporting-pane | 핵심 작업과 보조 정보를 분리하는 공간 원칙 | C의 두 표면 분리 및 좁은 화면 재배치 |

공식 출처:
- https://blitz.gg/overlays/tft
- https://github.com/HearthSim/Hearthstone-Deck-Tracker
- https://support.overwolf.com/en/support/solutions/articles/9000208995-how-to-use-outplayed
- https://raw.githubusercontent.com/changeroa/StyleGallery/main/patterns/split-sidebar/supporting-pane.md

HDT 이미지는 공식 저장소의 오래된 예시이며 현행 외형으로 주장하지 않습니다.
Mobalytics와 MetaTFT는 각각 접근 차단/정적 화면 부재로 시각 비교에서 제외했습니다.
다운로드한 공식 이미지 4장은 assets에 보존했습니다. 브랜드를 복제하는 것이 아니라
공간과 정보 구분 원칙을 참고했습니다.

## 시안과 실사용의 구분

40라·13스토리 완료·스모커 준비·브룩 1/2·선택위습 5개는 비교용 가상 상태입니다.
사용자의 실패 판을 재구성한 것이 아니며 B의 연결선은 전체 레시피가 아닌 목표 관계입니다.
실제 게임 배경은 사용자 제공 스크린샷을 로컬에서만 사용했습니다.
공략 판단 오류 수정 및 불릿 프로필 통계 연결은 별도 진행 항목입니다.

## 확인 범위

`preview.mjs`는 로컬 전용 서버와 브라우저를 사용해 데스크톱/390px 화면,
이미지 로딩, 가로 넘침, 세 가지 상태 전환을 확인합니다.
실제 WPF 반투명 렌더 성능과 게임 중 조작은 시안 선택 후 검증할 항목입니다.
