# 랜디픽 BETA 1.0.0

## 배포 범위

- 표시 버전: 랜디픽 BETA 1.0.0
- 배포 버전: `1.0.0-test.1` (Windows x64 테스트 채널)
- 확정안: 메인 B의 가로 메뉴/카드 배치 + 다크 색상, 원래 B 컴팩트 패수치 패널.
- 새 카드 R 체크 로고를 메인 리소스 및 실행 파일 아이콘에 적용.

## 기능 계약

일반 모드는 현재 패의 재료 확보율로 희귀함 → 전설 → 상위 → 방향별 유틸 후보를 탐색합니다. 상위 후보는 초월·제한·불멸·영원만 포함하며, 첫 상위 이후에는 전설과 이 네 상위 등급을 유틸별로 탐색합니다. 기존 자동 조합 안내는 초보자 모드에 남깁니다. 대깨와 직접 설정 모드는 유지합니다.

추천 순위, 선택한 유닛의 상세, 카테고리 펼침 상태는 독립적입니다. 재인식으로 순위가 바뀌더라도 선택 상세와 접힘 상태를 유지합니다. 민트는 재료가 가까운 참고 후보입니다. 직접 선택은 메인에서 파란 테두리, 오버레이에서 금색 테두리와 고정 패널로 구분합니다. 재료 확보율 100%는 즉시 제작 가능을 뜻하지 않습니다.

TMO 48129의 역할/수치/조건은 커뮤니티 참고자료입니다. `Data/randypick-utility-48129.json`과 `randypick-48129-provenance.md`에 정확 대응 및 제외 사유가 있습니다. 출처 충돌, 값 미상, 물리/마법 방향 미상은 임의로 보정하지 않습니다. 48784 패 수치 합계와 48129 역할 자료를 섞어 계산하지 않습니다.

B 패수치는 326×520 기본 크기이며 스턴 → 이감 → 방깎/마방깎 3열, 2열 지원 효과, 역할 칩, 접이식 조건/발동/출처 영역을 사용합니다. 수치가 미확정이면 `?`로 표시하고 충족 판단과 진행 막대 채움을 숨깁니다. 오래되거나 관측이 끊긴 패는 이전 수치를 숨깁니다.

메인은 한 덩어리의 모드 탭, 참고 추천 배너, 카테고리 칩과 선택 메뉴, 테두리가 구분되는 후보 카드로 구성합니다. 초보자/대깨의 목표·재료 영역과 다음 행동 영역은 1.2:1 비율을 사용합니다. 최소 920×620 창에서는 안내 문구와 칩을 간소화하되 모드·카테고리·선택 상세 접근은 유지합니다. 재료 계획이 없을 때는 `0/0` 대신 확인 대기를 표시합니다.

## 지원 한계 (중요)

이 릴리스는 UI 및 오프라인/기존 검증 경로 개선입니다. **Warcraft III 3.0 실시간 인식 지원을 새로 승인한 릴리스가 아닙니다.** 2.320의 live coaching, automatic navigation scoring 및 프로필 안전 가드는 그대로 유지합니다. 2.320 카탈로그가 선택되어 있다는 사실을 현재 게임의 검증된 패 관측으로 간주하지 않습니다. 미확인 상태에서는 후보와 상세 탐색을 제공하더라도 실시간 확보율·부족 판정을 만들지 않습니다.

게임 입력, 메모리 쓰기, 주입, 페이지 보호 변경 또는 MemoryDiagnostics 접근은 이 작업 범위에 포함되지 않습니다.

## 설치와 업데이트

1. 기존 랜디픽/OrandOverlay를 종료합니다.
2. 새 ZIP의 `OrandOverlay.exe`를 원하는 설치 폴더에 압축 해제합니다. 이전 EXE는 백업할 수 있습니다.
3. 실제 실행은 사용자가 수행합니다. 검증용 UI 캡처는 런타임과 분리된 Fixture로만 수행합니다.

기존 테스트 빌드는 자동 교체를 차단하므로, 테스트 채널을 갱신해도 기존 테스트 빌드에 자동 설치되지 않습니다. 수동 교체가 필요합니다. `%LOCALAPPDATA%\OrandOverlay` 설정/기록은 기존 버전과 공유하므로 샌드박스판이 아닙니다. 설정·기록은 ZIP에 포함하거나 교체하지 않습니다.

## 배포 안전

- self-contained single-file EXE와 README만 ZIP에 포함.
- ECDSA P-256 업데이트 서명을 앱에 내장된 공개키로 검증. Windows Authenticode 코드서명과는 다름.
- 새 불변 버전 파일을 먼저 올리고 공개 다운로드 길이/SHA-256을 대조한 후 테스트 채널 manifest만 갱신.
- 기존 stable, 프로필 채널, 이전 `.3` EXE는 변경하지 않음.
- 개인 서명 키, 자격증명, 로그, 설정, 소스는 배포 파일에 포함하지 않음.
