# 랜디픽 버전 표기

- 사용자에게 보이는 버전은 `BETA 1.0.3`, `BETA 1.0.4`, `BETA 1.0.5`처럼 숫자 세 자리로 통일한다.
- 사용자용 빌드를 올릴 때 `OrandOverlay.csproj`의 `Version` 마지막 숫자를 올린다. 메인·오버레이·능력치·업데이트 알림은 이 버전으로 표시한다.
- 같은 사용자 버전에 `recognition`, `ui`, 날짜, 수정 횟수 등의 접미사를 추가하지 않는다.
- 기존 테스터 앱의 업데이터 호환을 위해 서명 매니페스트·내부 빌드 식별자에는 `$(Version)-test.1`을 사용한다. 기존 클라이언트는 `-test.`로 업데이트 채널을 구분하므로 이 내부 표식을 제거하면 안정 채널로 바뀐다. 이 식별자는 기본 화면과 업데이트 안내에 노출하지 않는다.
- 진단 기록과 해시 검증에는 원래 빌드 식별자를 보존한다. 표시 변경을 이유로 서명 검증·채널 검증·게임 종료 후 수동 설치 원칙을 변경하지 않는다.
- 버전 변경과 로컬 빌드는 서버 게시를 의미하지 않는다. 공개 배포는 기존 검증·게시 절차를 따른다.
