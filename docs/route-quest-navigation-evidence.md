항법 선택은 저장된 NavigationMode 또는 24라운드 도달을 실제 선택 증거로 쓰지 않는다.
사용자의 게임 내 선택 확인과 자동 계산 후보는 별도이며 새 게임에서 초기화한다.

항로개척은 `WarcraftRouteQuestReader`가 읽기 전용으로 자동 확인한다. `SFN/oPN`
(66474–66502)은 Q000–Q016의 전역 풀에서 중복 없이 플레이어당 3개를 배정한다.
퀘스트별 배정 인덱스 배열은 해당 퀘스트의 소유자에게만 기록되며, 기본값 0은
배정 또는 완료의 증거가 아니다. 논리 배열 길이와 선행 기본값, 3슬롯 유일성,
남은 `Sh/Mh` 풀과 배정 집합의 상호 배타성을 함께 검사한다.

지원 런타임은 Warcraft III 2.0.4.23745와 위 맵 소스 프로필이다. 실행 파일 해시는
기존 인식 서비스가 검증하고, 실측 로컬 플레이어 슬롯이 없으면 읽기를 허용하지 않는다.
힙의 짧은 변수명과 타입이 맞는 연결 노드를 구조적으로 찾으며 고정 주소를 저장하지
않는다. 캐시 조회 시에도 타입·이름·배열·풀을 재검증하고 두 번 읽은 값이 같을 때만
사용한다. 인식 실패는 미확인, 실패 후 재탐색 간격은 10초다. 세션 경계에서 캐시를 비운다.

2026-09-06 실제 단독 플레이 관측에서 초월 완료, 리사이클 완료, 제한 진행 중이
읽혔다. 사용자가 리사이클의 클리어 표시를 별도로 확인했다. 첫 탐색 약 6초, 캐시
조회 약 1ms였다. 다인 플레이 소유권은 합성 메모리 테스트를 통과했지만 실게임
다인 플레이와 연속 새 게임 검증은 아직 별도 확인이 필요하다.

전체 퀘스트 종류는 고고학자, 오늘만산다, 목재수집, 도박중독, 하급/중급/고급 도박실패,
MVP 선정, 초월/불멸/영원/제한/왜곡/아이템 유닛조합, 콰트로, 트리플, 리사이클이다.
UI의 조건·보상은 각 등록 함수가 호출하는 `nfN/qoG` 정의에서 가져왔다.
보상 유닛명은 `map-source-metadata-2314.json`의 원본 WTS 매핑을 사용한다.

계산 경계:
- 퀘스트 상태: 미확인·미배정·진행 중·완료. 미확인/미배정/완료는 추가 보상 0.
- 실제 배정된 미완료 등급 조합 퀘스트만 현재 목표의 미래 보상에 반영한다.
  그 외 퀘스트는 조건·보상·완료 상태를 표시하되 도박 횟수나 판매 수를 추측하지 않는다.
- 이미 보유한 목표를 새로 조합할 계획이 없으면 추가 조합 보상을 약속하지 않는다.
- 오늘만산다는 마감 이후 활성 플래그가 남을 수 있다. 라운드만으로 완료를 추정하지 않는다.
- 목표 조합 후의 보상만 계산한다. 미래 보상으로 그 보상을 주는 조합을 먼저 만드는 순환은 금지.
- 두 퀘스트 목표는 명시적으로 켤 때만 추가 상위를 계획한다. 현재 목표와 공동 재료를
  공유 재고에서 한 번만 배분하고 가장 적은 부족 재료 경로를 비교한다.
- 관측/완료 이력/현재 목표는 같은 ID를 중복 계수하지 않는다. 실제 2기 보유는 수량으로 센다.
- 목표 묶음이 2기면 최상위 1기 항법은 제외한다. 보상 1개 때문에 자동으로 2기 목표를 강제하지 않는다.
- 골드·목재·기타 자원 또는 비흔함 재료가 부족하면 보상의 순잉여 점수는 0이다.
- 비용을 빼고 남는 흔함선택위습만 미래 상한 시나리오에 반영한다. 기준/하한은 원래 시나리오를 보존한다.
- 점수 단위는 묶음의 기초 재료 수로 정규화한 내부 효용이며 클리어 확률 또는 실제 패 완성률이 아니다.

기존 시뮬레이션 어댑터는 라인 처치 수·상자 경로 기여·실제 스킬 사용 등 미관측 값이 있다.
현재 점수는 이 입력 범위에서의 비교이지 실게임 바운티헌터 우월성의 증명이 아니다.
