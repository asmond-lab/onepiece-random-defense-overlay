## Meaning and consent
Observed inventory is a reference snapshot, not proof of ownership, alive state, complete inventory, actual craft execution or match outcome. Unknown round is absent, never zero. No conversion into legacy gameplay-v3 learning. Consent policy4 is required; policy3 is no longer sufficient at startup. Decline/close exits before production services. Version3 pending files are preserved and not relabeled. No nickname, chat, screenshots, persistent installation ID, process ID, executable path, memory address or free-form diagnostic text is collected. Server receipt time and per-fragment elapsedMs permit an anonymous event timeline; session IDs are regenerated across observed game context changes/app restarts.

## Verification distinction
Production-endpoint smoke probes use source=synthetic-validation and remain separate from source=live. A positive server ACK is not evidence that an actual player game was tested. Server-side query source=live for tester evidence. The source flag is supplied by the client and is a classification marker, not cryptographic proof.
