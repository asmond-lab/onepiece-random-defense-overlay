# 랜디픽 일반 모드 베타 배포

Warcraft III 3.0 / 원랜디 2.320 환경에서 사용할 **랜디픽 일반 모드 베타**를 공개합니다.

**버전: 1.0.2-test.3 · Windows 64비트**

[랜디픽 다운로드](https://orand-updates.epic42121.workers.dev/downloads/1.0.2-test.3/RandyPick.exe)

## 이번 베타에서 볼 수 있는 것

- 현재 패에서 가까운 희귀함 → 전설·히든 → 상위 → 주력 지원 후보를 안내합니다.
- 목표를 선택하면 **먼저 모을 재료의 이름과 부족 수량**을 초상과 함께 보여줍니다.
- 조합 순서는 **선택할 유닛 → 조합 키·횟수 → 결과 유닛**으로 확인할 수 있습니다. 이미 가진 중간 재료는 반영합니다.
- 스토리가 빠른 유닛, 물리·마법 유형, 이동 역할과 주력 궁합을 표시합니다.
- 스턴·이감·방깎·단일·끝딜·폭뎀증·마젠 등 전투 수치 창을 제공합니다. 미확정 값은 별도로 표시합니다.

## 실행과 업데이트

1. 다운로드한 **RandyPick.exe**를 실행하고 안내를 확인해 주세요.
2. Warcraft III 3.0에서 원랜디 2.320 게임에 입장합니다.
3. 일반 모드에서 패가 인식되는지 확인하고 목표 카드를 선택해 주세요.
4. ‘먼저 모을 재료’를 확인한 뒤 아래 조합 순서를 따라 **게임에서 직접** 조합하면 됩니다. 재료 목록을 접으면 조합 카드를 더 넓게 볼 수 있습니다.

이 배포본은 **베타 업데이트 채널**에 연결됩니다. 자동 업데이트를 켜두면 같은 채널의 새 버전을 확인하며, 게임 중에는 설치를 미룹니다. 앱 하단의 **업데이트 확인**으로 직접 확인할 수도 있습니다. 기존 앱에서 업데이트가 되지 않으면 위 링크로 이번 파일을 받아 실행해 주세요.

## 이번에는 일반 모드만 열립니다

**초보자·대깨·매뉴얼 모드는 잠금 상태**입니다. 일반 모드의 피드백을 먼저 반영한 뒤 개선해서 차례로 공개하겠습니다.

## 특히 확인해 주세요

- 실제 보유 패와 앱에 표시된 유닛·수량이 맞는지
- 뽑기·조합 후 목록과 부족 재료가 따라 바뀌는지
- 패 인식이 끊기거나 오버레이가 깜빡이는지
- 조합 키·선택 유닛·재료 수량이 실제 게임과 맞는지
- 추천 단계와 조합 안내를 게임 중에 빠르게 이해할 수 있는지

문제가 있으면 아래 형식으로 보내주시면 확인에 도움이 됩니다.

> 앱 버전: 1.0.2-test.3

> 직전에 한 행동: (뽑기, 조합, 창 전환 등)
> 실제 보유 유닛·수량:
> 앱에 표시된 내용:
> 기대한 내용:
> 가능하면 게임과 앱이 함께 보이는 화면 + 앱의 ‘제보용 정보 복사’ 내용

아직 베타입니다. 재료 비율 100%는 조합 가능 확정이 아니며, 자원·퀘스트 조건·미확인 단축키는 게임에서 확인해 주세요. 전투 수치에는 2.320에서 미검증된 참고값이 포함되어 있습니다. 앱은 조합 안내를 제공하며 게임 선택이나 키 입력을 자동 실행하지 않습니다.
