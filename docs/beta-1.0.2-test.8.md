# 랜디픽 일반 모드 베타 업데이트 — 1.0.2-test.8

조합할 때 부족한 재료와 다음 행동을 더 빠르게 볼 수 있도록 조합창을 개선했습니다.

**Warcraft III 3.0 / 원랜디 2.320 · Windows 64비트**

[랜디픽 다운로드](https://orand-updates.epic42121.workers.dev/downloads/1.0.2-test.8/RandyPick.exe)

## 달라진 점

- **탐색에서 목표를 선택하면 하단 중앙에 별도 조합창**이 열립니다. 다른 목표를 선택하면 같은 창에서 내용이 바뀝니다.
- 부족한 재료를 **유닛 초상·이름·수량으로 2열 표시**합니다. 탐색 카드의 중복 부족 문구는 정리했습니다.
- **선택할 유닛 → 조합 키·횟수 → 결과 유닛**을 가로로 배치해, 같은 공간에서 조합 순서를 더 많이 볼 수 있습니다.
- 이미 가진 중간 재료를 반영하고, 조합 후 새 패가 인식되면 안내를 다시 계산합니다.
- 조합창은 **항상 위에 고정**됩니다. ‘항상 위’ 체크박스와 X를 제거했고, 창이 가려진 상태에서 다시 열어도 앞으로 오지 않던 동작을 수정했습니다.
- 제목 부분을 잡아 위치를 옮기고, 가장자리로 크기를 조절할 수 있습니다.
- 기존 단계별 추천과 전투 수치 창을 유지했습니다. 좁은 탐색 카드의 한글 줄바꿈도 다듬었습니다.

## 실행과 업데이트

**기존 사용자:** 앱 하단의 **업데이트 확인**을 눌러 주세요. 자동 업데이트를 켜둔 경우에도 베타 채널에서 새 버전을 확인합니다. 게임 중에는 설치를 미룹니다.

**처음 사용하거나 업데이트가 되지 않는 경우:** 위 링크의 `RandyPick.exe`를 받아 실행해 주세요. 게임에 입장한 뒤 패 인식을 확인하고, 탐색에서 만들고 싶은 유닛을 선택하면 됩니다. 실제 유닛 선택과 조합은 게임에서 직접 해 주세요.

## 일반 모드부터 피드백을 받습니다

현재는 **일반 모드만 이용할 수 있습니다.** 희귀함 → 전설·히든 → 상위 → 주력 지원 순으로 추천을 안내합니다.

**초보자·대깨·매뉴얼 모드는 잠금 상태**이며, 일반 모드 피드백을 먼저 반영한 뒤 개선해 차례로 열 예정입니다.

## 이런 부분을 알려 주세요

- 실제 보유 유닛·수량과 인식 결과가 맞는지, 조합 후에도 갱신이 이어지는지
- 부족 재료와 조합 키·횟수를 게임 중에 빠르게 알아볼 수 있는지
- 조합창 위치·크기가 편한지, 게임 화면이나 조작을 지나치게 가리는지
- 패 인식 끊김, 창 깜빡임, 전투 수치 창이 사라지는 현상이 있는지

문제가 있으면 **앱 버전 / 라운드·선택 목표 / 직전에 한 행동 / 실제 상황과 앱 표시의 차이**를 함께 알려 주세요. 가능하면 게임과 앱이 함께 보이는 화면, 앱의 **제보용 정보 복사** 내용도 부탁드립니다.

아직 베타입니다. 재료 비율 100%만으로 완성이나 조합 가능 여부를 확정하지 않으며, 미확인 조합 키·자원·퀘스트 조건은 게임에서 확인해 주세요. 전투 수치에는 참고값이 포함됩니다. 실제 플레이에서의 인식 안정성과 사용성 피드백을 기다립니다.
