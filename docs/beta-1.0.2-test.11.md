랜디픽 베타 업데이트 · test.11

일반 모드 유틸 분류를 TMO 조합도우미처럼 딜 타입 안에서 다시 나눈 버전입니다.

다운로드:
https://orand-updates.epic42121.workers.dev/downloads/1.0.2-test.11/RandyPick.exe

이번 버전에서 확인할 내용:

- 첫 상위가 물딜이면 마젠/보잡/광잡이 물딜 칸만 보이는지. 징베는 `물딜+마젠`, 슈가는 그 칸에 없으면 됩니다.
- 보스 잡기와 광폭화 잡기가 따로 나뉘는지. 둘 다 있는 유닛은 양쪽 칸에 들어갑니다.
- 특별함·희귀함·전설·히든·해적선·세라핌·상위 중에서 유틸이 붙은 유닛이 유틸 칸에 보이는지
- 세라핌 분류
  - 호크: 물딜 방깎 / 보스 잡기 / 광폭화 잡기 / 암브
  - 샤크: 물딜 방깎 / 암브 / 공증 / 체젠
  - 베어: 마딜 보스 잡기 / 광폭화 잡기 / 마뎀증 / 마방깎
  - 스네이크: 마딜 폭뎀증 / 끝딜 / 범위 끝딜
  - 네 기 모두 공중이동

일반 모드만 열려 있습니다. 초보자·대깨·매뉴얼 모드는 아직 잠금 상태입니다.

실제 한 판에서 유틸 칸이 섞이거나 빠진 유닛이 있으면 알려 주세요.

이번 버전도 실제 게임 플레이 피드백을 받기 위한 베타입니다.
