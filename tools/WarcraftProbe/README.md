# WarcraftProbe 0.1.0

워크 업데이트 전후를 비교하기 위한 독립 실행형 진단 도구입니다. 랜디픽 본체나 게임 설정을 변경하지 않습니다.

## 가장 쉬운 사용법

1. 압축을 풀고 **WarcraftProbe.exe**를 실행합니다.
2. 메뉴 **1. 현재 워크 스냅샷**을 선택합니다.
3. **별도 폴더에 복사해 둔 Warcraft III.exe**의 전체 경로를 입력합니다. 설치된 원본 파일을 직접 지정하지 마세요.
4. 샘플 이름을 적습니다. 예: 업데이트 전, 업데이트 후, 조합 전, 조합 후.
5. 실행 파일 옆 **Captures** 폴더에 생성된 새 결과 폴더를 확인합니다.
6. 메뉴 **3. 두 스냅샷 비교**에서 이전/이후 결과의 snapshot.json을 지정합니다.

게임이 꺼져 있으면 메뉴 **2. 복사해 둔 EXE 기준선**으로 파일 자료만 저장할 수 있습니다. 복사본은 실행하지 않습니다.

## 업데이트 대응 순서

- 업데이트 전: 정상 동작하던 버전의 파일 기준선과 게임 스냅샷을 보관합니다.
- 업데이트 후: 새 실행 파일을 다시 복사하고, 가능한 비슷한 게임 상황에서 새 스냅샷을 저장합니다.
- 두 snapshot.json을 비교합니다. 같은 버전의 반복 캡처도 가능하지만, 실행 중 메모리 보호 상태가 바뀔 수 있으므로 모든 차이가 패치 때문인 것은 아닙니다.
- 보고서에서 바뀐 이름/타입 식별 위치, 섹션, 접근 상태를 확인한 뒤 판독기를 수정하고 검증합니다. **도구가 새 주소의 의미를 자동으로 확정하거나 랜디픽 프로필을 활성화하지는 않습니다.**

## 저장되는 것

- 복사본의 버전, SHA-256, PE 섹션과 일부 타입/이름 식별 위치
- 실행 중인 게임과 복사본의 제한된 대조 결과
- 메인 이미지의 메모리 구간별 접근 상태
- 확인된 빌드에서만 수행하는 제한된 함수 영역 해시 검사
- 3.0.0.24268의 정확한 알려진 파일에서만: 현재 뷰의 할당된 유닛 관측 개수와 rawcode
- snapshot.json 또는 comparison.json, 사람이 읽는 report.md, 두 파일만 묶은 report.zip

**전체 메모리 덤프가 아닙니다.** 게임 EXE/DLL 원본, 전체 힙, 채팅, 계정 정보, 설정, 전적 파일은 보고서에 넣지 않습니다. 게임에 입력을 보내거나 메모리를 쓰거나 보호 상태를 바꾸지 않습니다. 네트워크 전송과 텔레메트리도 없습니다.

## 중요한 해석 제한

- 현재 뷰는 내 플레이어라는 뜻이 아닙니다.
- 할당된 유닛 관측 목록에는 상점 등 보조 유닛이 포함될 수 있습니다. 살아 있는 내 패 전체 또는 성장 예약까지 포함한 목록이 아닙니다.
- 문자열 위치는 함수 코드 위치가 아닙니다. RTTI/vtable 후보도 필드 의미를 증명하지 않습니다.
- 읽기 불가/중복/불일치/시간 초과는 Unknown 또는 Blocked이며 0이 아닙니다.
- 알려지지 않은 새 빌드에는 기존 객체 주소를 적용하지 않습니다. 파일·모듈 진단이 가능하더라도 게임플레이 판독은 승인하지 않습니다.
- 헤더와 리소스 대조는 실행 중 전체 코드의 해시 검증이 아닙니다. 게임을 일시 중지하지 않으므로 원자적 스냅샷도 아닙니다.
- 메모리 읽기는 최대 8 MiB, 캡처 단계는 최대 10초, 구조 관측은 발견·재검증 포함 3초 미만으로 제한됩니다. 경계 시각은 만료로 처리합니다. 읽을 수 없는 영역은 건너뛰어 코드로 해석하지 않습니다.
- 현재 실행 파일의 Windows 게시자 서명(Authenticode)은 없습니다. 배포 파일의 SHA-256은 함께 제공되는 검증 기록으로 확인할 수 있습니다.

## 명령줄

공백이 있는 경로는 따옴표로 감싸세요. 모든 출력은 **새 폴더**여야 하며 기존 결과를 덮어쓰지 않습니다.

~~~powershell
.\WarcraftProbe.exe capture --copy "C:\WarcraftCopies\Warcraft III.exe" --label "업데이트 전" --out "C:\WarcraftCaptures\before"
.\WarcraftProbe.exe inspect --copy "C:\WarcraftCopies\Warcraft III.exe" --label "파일 기준선" --out "C:\WarcraftCaptures\file-before"
.\WarcraftProbe.exe compare --before "C:\WarcraftCaptures\before\snapshot.json" --after "C:\WarcraftCaptures\after\snapshot.json" --out "C:\WarcraftCaptures\comparison"
~~~

capture에 --metadata-only를 붙이면 유닛 구조 관측을 요청하지 않습니다. 자동 조사에서는 --pid와 --started-at을 함께 지정해 정확한 프로세스 시작 시각까지 고정할 수 있습니다. 두 옵션을 생략하면 실행 중인 워크가 하나일 때만 선택합니다. 게임은 사용자가 직접 플레이하며 조합/선택을 자동 수행하지 않습니다.

종료 코드 0은 보고서 저장 완료를 뜻합니다. **스냅샷 내부의 Complete/Observed/Unknown/Blocked와 제한을 별도로 확인해야 합니다.** 2는 입력·검증·파일 오류, 3은 밖으로 전달된 취소입니다.

## 이번 버전 검증

- 도구 테스트: 285 통과, 실패/건너뜀 0 (배포 전 최종 재실행 기록 참조).
- 허용된 3.0.0.24268 복사본의 파일 기준선 생성 확인.
- 정확히 고정한 실행 중 게임에서 두 번의 제한된 캡처와 비교 보고서 생성 확인.
- 실제 패치 전후의 두 다른 워크 버전을 실측 비교한 것은 아닙니다. 버전/구조 변화 비교는 합성 테스트로 검증했고, 현재 게임에서 반복 캡처를 확인했습니다.
