# 원피스 랜덤 디펜스 오버레이

워크래프트3 유즈맵 **원랜디(원피스 랜덤 디펜스)** 를 도와주는 프로그램입니다.

게임을 켜면 화면 한쪽에 작은 창(오버레이)이 떠서, **지금 내 패로 뭘 만들면 좋은지**를
실시간으로 알려줍니다. 추천은 감이 아니라 **실제 고수들이 신 난이도 이상을 깬 기록
3만 판**을 분석한 결과를 기반으로 합니다.

## 무엇을 보여주나요

- **추천 조합**: 내가 고른 상위 유닛(상디, 니카, 빅맘 등)에 맞춰, 지금 패에서 가장
  만들 가치가 있는 유닛들을 순서대로 보여줍니다. 각 추천에는 "고수들이 몇 퍼센트나
  같이 썼는지"가 근거로 붙습니다.
- **내 패 점수판**: 스턴·이동속도 감소·방어력 감소 같은 핵심 수치가 목표에 얼마나
  찼는지 게이지로 보여줍니다. 아이템과 그린블러드 효과도 합산됩니다.
- **지금 조합 가능**: 재료가 다 모인 유닛이 생기면, 어떤 유닛을 고를지 알려줍니다.
  실제 선택과 키 입력은 언제나 사용자가 직접 합니다.
- **자잘한 판단 도우미**: 남는 희귀 패를 팔지 리롤할지, 특수함 유닛을 분해할지,
  그린블러드를 누구에게 줄지, 긴급소집 와일드카드를 어디에 쓸지 등을 안내합니다.

게임 상황도 따라갑니다 — 항법(바운티헌터, 긴급소집 등), 오로성 효과, 마딜/물딜 차이,
니카의 이감/노이감 같은 빌드 갈림길까지 반영해서 추천이 달라집니다.

## 다운로드

[Releases](https://github.com/AsmondKR/onepiece-random-defense-overlay/releases)에서
`OrandOverlay.exe` 파일 하나만 받으면 됩니다. 설치 과정 없이 바로 실행됩니다.

## 사용법

1. `OrandOverlay.exe`를 실행합니다. (설치 불필요, Windows 전용)
2. 설정 창에서 **목표 상위 유닛**을 고르고 **항법 자동 추천**을 확인합니다.
3. **워크래프트3를 켜면** 내 패를 자동으로 인식합니다. (티모지지 불필요)
4. 게임 중에는 **Caps Lock** 키로 오버레이를 켜고 끌 수 있습니다.

### 항법 추천은 안내만 합니다

오버레이의 항법 기능은 **RECOMMENDS(추천)** 를 보여주는 안내 창입니다. 워크래프트
안에서 항법은 사용자가 직접 선택해야 합니다. 오버레이는 항법을 선택하거나 클릭하지
않고, 키를 누르거나 어떤 게임 입력도 대신하지 않습니다.

**항법 자동 추천**은 기본으로 켜져 있습니다. 라운드 21~23의 안전한 추천이 나오면
오버레이 설정의 항법만 자동으로 바뀝니다. 자동 추천이 켜져 있으면 수동 항법 선택
상자는 숨겨집니다. 자동 추천을 끄면 선택 상자가 나타나며 항법을 직접 설정할 수 있습니다.

- **라운드 20 preview**: 다음 항법 후보를 미리 보여주는 미리보기입니다.
- **라운드 21~23 actionable recommendation window**: 선택 가능한 추천 창이지만,
  워크래프트에서 항법을 실제로 고르는 일은 사용자가 직접 합니다.
- **라운드 24 source-expected**: 소스가 기대하는 문구로 `강제 Double Benefit`을
  표시할 수 있습니다. 이는 게임에서 선택되었다는 **runtime-confirmed selection**
  확인이 아니며, 오버레이는 그런 선택을 했다고 주장하지 않습니다.

추천이 떠도 반드시 워크래프트 UI에서 직접 항법을 선택하세요. 오버레이는 추천만 하고
선택·클릭·키 입력을 수행하지 않습니다.

## 자주 묻는 질문

**게임에 위험하지 않나요?**
이 프로그램은 게임을 **읽기만** 합니다. 게임 메모리에 쓰거나, 코드를 심거나, 키보드·
마우스를 대신 조작하는 기능이 전혀 없습니다. 검증된 빌드 프로필이 없으면 자동 인식이
스스로 꺼지도록 만들어져 있습니다.

**추천은 어떻게 만들어지나요?**
티모지지에 공개된 신·악몽 난이도 클리어 기록을 기반으로, 상위 유닛별로 "고수들이
실제로 뭘 같이 썼는지"를 학습합니다. 기록이 부족한 조합은 커뮤니티 공략을 대신 씁니다.

기록 집계는 개발자가 이 저장소에 미리 올려 두며, **사용자 프로그램은 티모지지 서버에
접속하지 않고** 이 저장소에서만 데이터를 받습니다. 새 집계가 올라오면 추천도 자동으로
갱신됩니다.

**어떤 유닛을 지원하나요?**
클리어 기록이 충분히 쌓인 상위 유닛만 목표로 고를 수 있게 되어 있습니다(현재 78종).
데이터가 없는 유닛을 억지로 추천하지 않기 위해서입니다.

## 고지

비공식 팬 도구입니다. 원피스 랜덤 디펜스 제작진, 티모지지(TMO.GG)와 아무 관련이
없습니다. 유닛 정보와 클리어 기록은 티모지지 공개 자료를 출처로 합니다.
