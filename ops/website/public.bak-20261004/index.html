03 / How it works

설치 없이.
네 단계면 끝.

Windows용 EXE 하나로 실행합니다. 게임을 켜면 내 패를 자동으로 인식하고, 게임 중에는 F1로 오버레이를 켜고 끕니다.

다운로드 · 준비 중

  1. 01 / 실행

    프로그램 실행

    EXE 파일 하나를 실행합니다. 설치 과정은 없어요. Windows에서만 동작합니다.

  2. 02 / 모드

    모드 고르기

    초보자, 일반, 대깨, 매뉴얼 중 하나를 고릅니다. 초보자와 일반은 같은 자동 추천을 쓰고 설명의 양만 다르며, 매뉴얼에서는 상위 목표를 두 개까지 정할 수 있어요.

  3. 03 / 시작

    워크래프트 III 시작

    게임을 켜면 내 패를 자동으로 인식합니다.

  4. 04 / 토글

    F1로 켜고 끄기

    게임 중 F1을 누르면 오버레이가 나타나거나 사라집니다. 기본값이고, 다른 키로 바꿀 수 있어요.

안전. 읽기만 하고, 대신 누르지 않아요.

04 / Safety

  • Safe.01

    키 입력이나 클릭을 대신하지 않습니다. 선택은 언제나 직접 합니다.

  • Safe.03

    검증된 빌드 프로필과 맞지 않으면 자동 인식이 스스로 꺼집니다.

  • Safe.04

    플레이 기록 수집은 동의 창에서 동의한 경우에만 이루어집니다.

질문. 자주 묻는 것들.

01지금 내려받을 수 있나요?

아직은 아니에요. 안정 버전을 준비하고 있고, 다운로드는 준비 중입니다.

02어떤 환경에서 쓸 수 있나요?

Windows 전용입니다. 워크래프트 III 유즈맵 원랜디(원피스 랜덤 디펜스)를 위한 도구예요.

03게임에 위험하지 않나요?

랜디픽은 게임을 읽기만 합니다. 게임 메모리에 쓰거나 코드를 주입하지 않고, 키 입력이나 클릭을 대신하지도 않습니다. 검증된 빌드 프로필이 없으면 자동 인식이 스스로 꺼집니다.

04항법도 대신 골라 주나요?

아니요. 항법은 추천만 보여 줍니다. 실제 선택은 워크래프트 안에서 직접 해 주세요.

05모드는 어떻게 다른가요?

초보자, 일반, 대깨, 매뉴얼 네 가지가 있습니다. 초보자와 일반은 같은 자동 추천을 쓰고 설명의 양만 다르며, 매뉴얼에서는 상위 목표를 두 개까지 정할 수 있습니다.

06제 플레이 기록이 수집되나요?

동의 창에서 동의한 경우에만 플레이 기록을 수집합니다.

07켜고 끄는 키를 바꿀 수 있나요?

네. 기본값은 F1이고 다른 키로 바꿀 수 있습니다.
