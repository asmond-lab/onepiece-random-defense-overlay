01 / Features

닫기

기능. 지금 해야 할 판단을 한 화면에.

추천마다 고수들이 같은 선택을 얼마나 했는지가 함께 표시됩니다.

  1. 01

    추천 조합

    고른 상위 목표에 맞춰, 지금 패에서 만들 가치가 큰 유닛을 순서대로 보여 줍니다. 각 추천에는 고수들이 같은 것을 만든 비율이 근거로 붙습니다.

  2. 02

    내 패 점수판

    스턴, 이동속도 감소, 방어력 감소가 목표치에 얼마나 찼는지 게이지로 보여 줍니다. 아이템과 그린블러드 효과도 함께 계산합니다.

  3. 03

    지금 조합 가능

    재료가 다 모인 유닛이 생기면 바로 알려 줍니다. 무엇을 고르고 어떤 키를 누를지는 언제나 직접 정합니다.

  4. 04

    판단 도우미

    남는 희귀 패를 팔지 리롤할지, 특수함 유닛을 분해할지, 그린블러드를 누구에게 줄지, 긴급소집 와일드카드를 어디에 쓸지 안내합니다.

게임 상황도 따라가요

  • 항법 · 바운티헌터 · 긴급소집
  • 오로성 효과
  • 마법 딜 / 물리 딜
  • 니카 빌드 갈림길

항법은 추천만 합니다. 실제 선택은 워크래프트 안에서 직접 해 주세요.

02 / Data

닫기

근거. 감이 아니라 클리어 기록에서.

학습한 클리어 기록 · 신+
30,000판

78종
추천 모드
4개

  • 고수들의 실제 선택을 학습

    신 난이도 이상을 깬 약 3만 판의 기록에서, 상위 목표별로 고수들이 무엇을 함께 만들었는지 배웁니다.

  • 근거가 보이는 추천

    추천마다 고수들 중 몇 퍼센트가 같은 것을 만들었는지 함께 보여 줍니다.

  • 기록이 적을 때는 공략으로

    기록이 충분하지 않은 경우에는 커뮤니티 공략을 대신 참고합니다.

티모지지(TMO.GG) 공개 기록 중 신·악몽 난이도 클리어 기록을 상위 유닛별로 학습합니다. 랜디픽 프로그램은 티모지지 서버에 직접 접속하지 않아요.

03 / How it works

닫기

설치 없이. 네 단계면 끝.

  1. 01 / 실행

    프로그램 실행

    EXE 파일 하나를 실행합니다. 설치 과정은 없어요. Windows에서만 동작합니다.

  2. 02 / 모드

    모드 고르기

    초보자, 일반, 대깨, 매뉴얼 중 하나를 고릅니다. 초보자와 일반은 같은 자동 추천을 쓰고 설명의 양만 다르며, 매뉴얼에서는 상위 목표를 두 개까지 정할 수 있어요.

  3. 03 / 시작

    워크래프트 III 시작

    게임을 켜면 내 패를 자동으로 인식합니다.

  4. 04 / 토글

    F1로 켜고 끄기

    게임 중 F1을 누르면 오버레이가 나타나거나 사라집니다. 기본값이고, 다른 키로 바꿀 수 있어요.

다운로드는 아직 열리지 않았어요. 안정 버전을 준비하고 있습니다. 다운로드 · 준비 중

05 / FAQ

닫기

질문. 자주 묻는 것들.

01지금 내려받을 수 있나요?

아직은 아니에요. 안정 버전을 준비하고 있고, 다운로드는 준비 중입니다.

02어떤 환경에서 쓸 수 있나요?

Windows 전용입니다. 워크래프트 III 유즈맵 원랜디(원피스 랜덤 디펜스)를 위한 도구예요.

03게임에 위험하지 않나요?

랜디픽은 게임을 읽기만 합니다. 게임 메모리에 쓰거나 코드를 주입하지 않고, 키 입력이나 클릭을 대신하지도 않습니다. 검증된 빌드 프로필이 없으면 자동 인식이 스스로 꺼집니다.

04항법도 대신 골라 주나요?

아니요. 항법은 추천만 보여 줍니다. 실제 선택은 워크래프트 안에서 직접 해 주세요.

05모드는 어떻게 다른가요?

초보자, 일반, 대깨, 매뉴얼 네 가지가 있습니다. 초보자와 일반은 같은 자동 추천을 쓰고 설명의 양만 다르며, 매뉴얼에서는 상위 목표를 두 개까지 정할 수 있습니다.

06제 플레이 기록이 수집되나요?

동의 창에서 동의한 경우에만 플레이 기록을 수집합니다.

07켜고 끄는 키를 바꿀 수 있나요?

네. 기본값은 F1이고 다른 키로 바꿀 수 있습니다.
