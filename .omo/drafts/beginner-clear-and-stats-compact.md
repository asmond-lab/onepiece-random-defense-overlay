## 사용자 관찰
- 총 11클 중 대부분은 TMO만 사용했고, 오버레이 사용 후에도 단독으로 클리어하기 어려웠다.
- 물딜에서 방깎을 별도로 설계해야 했고, 다상위를 따라가다 55라운드 전후 방깎·이감 부족으로 죽는 경우가 있었다.
- 현재 패수치(방깎·이감 포함)만 화면에 남기고 싶지만 기존 창은 그렇게 최소화할 수 없다.

## 결정 장부
- 조합식 권위: TMO 42479.
- 추천의 최우선 목표: 상위 수를 늘리는 것보다 현재 주딜이 요구하는 생존 지원 수치 확보.
- 패수치 단독 모드의 핵심: 추천 보드만 숨겨도 기존 패수치는 전부 실시간 갱신.
- 권장 기본값: `초보 안전 모드` 활성. 표본 수가 많다는 이유만으로 다상위를 자동 선택하지 않는다.
- 원딜/다상위 분류: 명시적 목표 메타데이터를 우선하고, 클리어 표본은 보조 증거로만 사용한다.
- 패수치 단독 모드: 기존 `StatsOverlayWindow`의 내용·크기를 유지하고 추천 창만 숨긴다.

## 조사 장부
- [x] 현재 다상위 추천 진입 조건: `multi sample > solo sample`이면 자동으로 다상위 계열을 고른다.
- [x] solo-carry 구분: 설명의 `솔딜` 텍스트 외에는 강한 분류가 없고, 표본의 상위 기수는 의도와 다를 수 있다.
- [x] 현재 물딜 핵심 목표: 방깎 211, 이감 102, 안정 스턴 1.4.
- [x] 기존 Stats 창: 별도 창은 이미 있으나 부모 추천 창과 표시/숨김이 강결합되어 있고 비핵심 패널까지 항상 표시된다.
- [x] 설정: 두 창 위치는 저장하지만 표시 모드는 저장하지 않는다.
- [x] 테스트 전략: TDD. 추천 분류·수치 게이트는 순수 정책 테스트, 표시 모드는 visibility/layout/settings 테스트 후 실제 WPF QA.

## 추천 설계 A — 초보 클리어 안전 모드
1. 목표 상위마다 `SoloPreferred`, `MultiAllowed`, `MultiRequired`, `Unknown`을 명시한다.
2. 자동 항법은 표본 수 우세만으로 바꾸지 않는다. 명시 분류가 없으면 `Unknown`으로 두고 현재 선택을 유지한다.
3. 주딜 상위를 완성한 뒤 방깎 211·이감 102·안정 스턴 1.4를 `55라 준비 게이트`로 평가한다.
4. 물딜 게이트 미달이면 두 번째 상위 카드를 잠그고 부족 수치를 채우는 지원 유닛만 추천한다.
5. 마딜은 물딜 방깎 대신 마방깎 공급원 게이트를 사용하되 이감·스턴은 동일하게 확인한다.
6. 추천 계산과 패수치 표시가 같은 수치 계산기를 사용해 조건부 방깎·이감의 불일치를 없앤다.
7. 카드에 `1상위 권장`, `다상위 가능`, `55라 준비 미달 — 2상위 보류`를 직접 표시한다.

### 설계 A 수용 기준
- 다상위 표본이 더 많아도 `SoloPreferred` 목표는 자동으로 다상위로 바뀌지 않는다.
- 방깎/이감/스턴 중 하나라도 미달이면 두 번째 상위 추천이 지원 추천보다 앞서지 않는다.
- 세 수치가 모두 충족된 뒤에만 `MultiAllowed`의 추가 상위가 열린다.
- UI 패수치와 추천 엔진의 현재/목표 수치가 항상 동일하다.

## 추천 설계 B — 기존 패수치 단독 모드
1. `OverlayDisplayMode = Full | StatsOnly | Hidden`을 설정에 저장한다.
2. `StatsOnly`에서는 추천 창만 숨기고 기존 `StatsOverlayWindow` 전체를 독립 표시한다.
3. 상단에 `55라 준비` 상태를 두고 스턴·이감·방깎(마딜은 마방깎)을 현재/목표 형식으로 표시한다.
4. 공격력·공속·재생 등 나머지 패수치는 작은 보조 칩으로 유지하고, 리롤·긴급·특별함·그린블러드 추천 패널은 접는다.
5. 메인 설정에 `전체 / 패수치만 / 숨김` 선택을 추가하고 기존 위치·클릭 통과·배율·드래그를 그대로 사용한다.
6. 추천 창 닫기나 일시적 인식 오류가 기존 Stats 창을 함께 숨기지 않도록 visibility 결합을 해제한다.

### 설계 B 수용 기준
- 패수치만 모드에서 추천 보드가 보이지 않고 핵심 수치는 계속 실시간 갱신된다.
- 재시작 후 모드와 통계 창 위치가 복원된다.
- 일시적 인식 실패에는 깜빡이지 않고, 실제 세션 종료 시에만 숨는다.
- FHD/울트라와이드/혼합 DPI에서 핵심 KPI가 잘리지 않는다.
